## FileTransferWithSSH

- …

## ModelValidator

根据offline表的model字段注册校验规则，校验规则配置在数据字典中`COMMON_DOWNLOAD_API_RULE`

- model参数需要在`self.model_rule_map`的key中存在，否则未注册规则
- 支持链式调用

```python
# PyVbord/apps/Commons/common_utils.py
class ModelValidator:
    """
    通用校验主类：
    1.  直接注册规则类（无需实例化）
    2.  validate仅接收model和data参数
    3.  调用run()方法执行校验并返回字符串结果
    """
    def __init__(self):
        # 注册表：键为model名称，值为对应的 model_en ”规则类（非实例）“、”额外参数字典“
        self.model_rule_map = {}
        # 缓存待校验的参数（model + data）
        self.pending_model = None
        self.pending_data = None

    def register_model_rules(self, model, rule_class, **rule_kwargs):
        """
        直接注册 model_en 规则类（无需实例化，传入类本身即可）
        :param model:  model_en 名称（字符串，如"Traceback"）
        :param rule_class: 对应 model_en 的规则类（如TracebackRules）
        :param rule_kwargs: 该模型校验规则的额外参数（全局/通用参数）
        """
        pass

    def validate(self, model, data):
        """
        仅接收model和data两个参数，缓存待校验信息（不立即执行校验）
        :param model: 目标 model_en 名称
        :param data: 待校验数据（任意类型）
        :return: self 支持链式调用（如 validator.validate("Traceback", data).run()）
        """
        pass
    
    def validate(self, model, data):
        """
        仅接收model和data两个参数，缓存待校验信息（不立即执行校验）
        :param model: 目标 model_en 名称
        :param data: 待校验数据（任意类型）
        :return: self 支持链式调用（如 validator.validate("Traceback", data).run()）
        """
        pass
    
    def run(self):
        """
        执行校验逻辑，返回最终字符串结果（校验入口方法）
        :return: 拼接后的错误信息字符串（无错误返回空字符串）
        """
        pass
    def _reset_pending_params(self):
        """重置缓存的待校验参数（私有辅助方法）"""
        self.pending_model = None
        self.pending_data = None
    
```

**使用方式**

```python
# 实例化
validator = ModelValidator()
# 注册规则
validator.register_model_rules(model_en, FileCheck, **rule_dict)  # 根据 model_en 注册规则
# 缓存校验并执行校验
rule = validator.validate(model=model_en, data=data).run()  # rule是校验完毕后的str类型，拼接的字符串，校验通过则rule为空串
```

- model_en：model名称（str），需要在数据字典中`COMMON_DOWNLOAD_API_RULE`的key进行配置

- FileCheck：规则校验类，会校验所有`check_`字符开头的方法

  ```python
  # 示例
  class FileCheck:
      """ 会校验所有 'check_' 字符开头的方法 """
  
      def check_filesize(self, data, **kwargs):
          file_path = data.get('file_path', '')
          file_size = os.path.getsize(file_path)
          max_size = kwargs.get('max_size', 0)
          max_size_errmsg = kwargs.get('max_size_errmsg', '')
          if max_size and ((file_size / 1024 / 1024) > int(max_size)):
              return max_size_errmsg
          return ''
  ```

- rule_dict：注册的规则，a)可以配置在数据字典`COMMON_DOWNLOAD_API_RULE`；b)也可以在代码中定义成常量

  ```python
  # 示例
  {
      'BadBoard-SingleLog': {'max_size': 300, 'max_size_errmsg': '校验不通过的错误提示消息'},
      'BadBoard-BBU_LOG': {'max_size': 300, 'max_size_errmsg': '校验不通过的错误提示消息'},
      ......
  }
  ```
